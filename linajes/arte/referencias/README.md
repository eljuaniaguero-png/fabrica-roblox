# Referencias

Capturas de otros juegos de Roblox, de portadas y de cómics. **Solo sirven para sacar ideas:** nunca se suben a Roblox ni se copian (nombres, íconos, textos, trajes ni logos). Lo que tomamos de cada una está en `../GUIA-ESTILO.md`.

| Carpeta | Qué hay | Para qué sirve |
|---|---|---|
| `interfaz/` | Menú de espacios, lista de Linajes con %, barras, lista de jugadores por bando, árbol de habilidades, diálogo con NPC | Cómo se ordenan las pantallas |
| `combate/` | Dash con rayos, flechas y zonas rojas de aviso, barras y botones de habilidad, poder de noche | Efectos de poder y avisos de ataque |
| `mundo/` | Objeto que brilla con columna de luz, ruinas con niebla, paredes sucias y telarañas, ciudad junto al agua, ciudad de cómic de noche | Clima, texturas y ciudad |
| `npcs/` | NPC sentado bajo la lluvia | Cómo se presenta un NPC para hablarle |
| `trajes/` | Traje de velocista (pantalla de trajes y detalle), capa de vigilante de espalda | Cuánto detalle lleva un traje sobre el avatar de bloques |
| `portadas/` | Portadas de juegos de héroes (grupo, tejado de noche, vuelo) | Composición y luz para nuestras miniaturas |

Si llegan capturas nuevas, van en la carpeta que corresponda con el número que sigue y un nombre que diga qué muestran (`mundo/07-callejon-con-lluvia.png`).
