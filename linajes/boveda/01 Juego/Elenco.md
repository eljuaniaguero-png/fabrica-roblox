# Elenco

Regla: **copiamos el tipo de personaje, no el personaje.** Cambiar solo el nombre no alcanza: si un héroe tiene el mismo símbolo, traje, colores y origen que Batman, sigue siendo Batman para Warner. Por eso cada uno cambia **nombre + tema visual + origen + debilidad**, y mantiene el rol que lo hace sentir DC.

| DC (nombre de trabajo) | Nombre final | Qué lo hace distinto |
|---|---|---|
| Batman | **Cuervo** | Tema cuervo (no murciélago), ex policía que perdió a su compañero, capa de plumas metálicas, gancho y bombas de humo |
| Superman | **Centinela Solar** | Último de un pueblo nacido dentro de una estrella. Se debilita en la oscuridad del eclipse (no una piedra verde). Blanco y dorado, sin letra en el pecho |
| Wonder Woman | **Atalanta** | Viene de las Hespérides (mito griego, libre). Lanza y escudo, sin lazo ni tiara |
| Flash | **Estela** | Velocidad que le dio el rayo del eclipse. Violeta, deja estelas de luz, sin rayo en el pecho |
| Green Lantern | **Arquitecto** | Guantelete tecnológico que fabricó él mismo. Sin anillo, sin cuerpo de guardianes, sin juramento |
| Aquaman | **Heredero Abisal** | Príncipe de una ciudad hundida bajo Puerto Óxido, controla presión y corrientes |
| Cyborg | **Bastión** | Héroe con implantes (une con el sistema de implantes del juego) |
| Joker | **Mascarada** | Villano teatral de máscaras que cambia de "personaje" en cada pelea. Nada de payaso ni sonrisa pintada |
| Lex Luthor | **Víctor Halden** | Dueño de Corona Corp, vende implantes ilegales |
| Darkseid | **El Eclipsador** | Causó el eclipse, quiere juntar todos los Linajes |
| Liga de la Justicia | **Liga de Guardianes** | |
| Legión del Mal | **Cofradía Carmesí** | (reemplaza a "Sindicato Carmesí", que se parecía a un grupo de DC) |
| Gotham / Metrópolis | **Ciudad Vórtice** / **Distrito Corona** | |
| Daily Planet | **El Faro** | |
| Arkham | **Penal Islaroca** | |

Por pedido de Juani, mientras diseñamos usamos los nombres de DC como **nombres de trabajo**; antes de publicar se reemplazan por la columna "Nombre final". La lista completa (16 personajes, 7 NPCs, 10 lugares) está en el sistema de diseño **Linajes del Eclipse 3D**, sección Modelos: https://claude.ai/artifact/WJxLkCEZEGJWzWzuyeU49y
Nada de logos, trajes ni frases de DC en los modelos: el diseño es nuestro desde la primera hoja de concepto.
